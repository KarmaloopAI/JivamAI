v0.3.0
Code Mode & File Attachments Latest
May 5, 2026
Code Mode screenshot
✦ New
Code Mode — A focused coding environment with syntax-aware diffs, one-click copy, and line-level commenting.
File attachments — Drag and drop files, images, and PDFs directly into any conversation.
Web search — Jivam can now search the web in real-time when answering questions.
Keyboard shortcuts — Full keyboard navigation. Press ⌘K to open the command palette.
↑ Improved
Response speed — Average first-token latency reduced by 40% with streaming improvements.
Conversation sidebar — Grouped by date, searchable, and sortable by recency or name.
✓ Fixed
Fixed a crash on Windows 11 when pasting large text blocks.
Markdown rendering now correctly handles nested lists and fenced code blocks.
v0.2.0
Dark Mode & System Themes
Apr 14, 2026
✦ New
Dark mode — Auto-switches with your system theme. Manually override in Settings.
Krutrim Cloud model switcher — Switch between Sarvam-105B, Krutrim-1, and Llama 3.1 from the toolbar.
Export conversations — Export any conversation as Markdown or PDF.
↑ Improved
Token usage display — See per-message token counts and session totals in the sidebar.
Linux packaging — Now distributed as both .deb and .AppImage.
✓ Fixed
Fixed auto-scroll breaking when editing a message mid-stream.
Corrected Hindi text rendering alignment in RTL-mixed contexts.
v0.1.0
Initial Release
Mar 20, 2026
✦ New
Conversation Mode — Full multi-turn conversations powered by Sarvam-105B.
Desktop app — Available for macOS (Apple Silicon + Intel), Windows 10/11, and Linux (Debian/Ubuntu).
Conversation history — Sessions saved locally, searchable from the sidebar.
Markdown rendering — Full Markdown support with code highlighting across 40+ languages.
22 Indian languages — Native multilingual support via Sarvam-105B.

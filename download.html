Download

Get Jivam running.

One command sets up Node.js, installs Jivam, and puts it on your computer as a desktop app. Free to use with your own Sarvam AI or Krutrim Cloud API key.

macOS

Run this in Terminal. It adds Jivam to your Applications folder.

curl -fsSL https://jivamai.com/install.sh | bash
Uses the WebKit built into macOS

Windows

Run this in PowerShell — no admin rights needed. It adds Jivam to your Start menu and Desktop.

irm https://jivamai.com/install.ps1 | iex

Using Command Prompt instead of PowerShell? This works from either:

powershell -c "irm https://jivamai.com/install.ps1 | iex"
Windows 10/11 Uses Microsoft WebView2 (set up for you if it's missing)

Linux

A native Ubuntu app is coming. Until then Jivam runs in your browser: run the installer, then start it with jivam serve and open the address it prints.

curl -fsSL https://jivamai.com/install.sh | bash
Runs in your browser today Desktop app: coming soon

What happens when you run it

  1. 1

    Checks (and installs) Node.js

    If Node.js 20+ isn't already on your machine, the script installs the latest LTS release for you — nothing to do manually, and no admin rights required (on Windows, it falls back to a per-user install if it can't get elevated permissions).

  2. 2

    Installs Jivam globally via npm

    npm install -g jivamai jiva-core — the Jivam CLI and the underlying agent engine, both pulled straight from the npm registry.

  3. 3

    Builds the app on your computer

    The script runs jivam install, which makes a small launcher for Jivam right on your machine: Jivam.app in your Applications folder on macOS, a Start menu and Desktop shortcut on Windows. The window is the web view your system already has (WebKit on macOS, WebView2 on Windows), so there is no big download, no signed installer for your system to question, and no background service. If an older version of Jivam left a background service or a Safari or Edge web app behind, the installer removes it. On a Windows 10 PC without WebView2, it offers Microsoft's own installer.

  4. 4

    Launch it

    Jivam opens when the install finishes. After that, start it from Launchpad, Spotlight or the Dock on macOS, or from the Start menu on Windows. Closing the window quits Jivam. It runs only on your computer — nothing leaves it except your model API calls. When a new version is out Jivam tells you, and one click on Update installs it and restarts Jivam.

Stuck on install?

  • Ask Jivam what's wrong

    Run jivam check. It tests the app launcher and the window and says which one fails.

  • Read the log

    Jivam writes what it did to ~/.jivam/jivam.log (on Windows, %USERPROFILE%\.jivam\jivam.log).

  • Run the installer again

    It is safe to repeat. jivam install alone rebuilds just the app.

  • Remove the app

    jivam uninstall removes the app. Your settings, API keys and conversations stay in ~/.jivam.

  • Still stuck?

    Email hello@jivamai.com with the last lines of the log.
